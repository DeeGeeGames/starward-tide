# Capital warship study

The tracked result is [approved version 3](v3/README.md). It has a deep hull, rounded shoulders, stepped bridge, opposing twin main batteries, and a 16% narrower beam than the preceding volume study.

Versions 1 and 2 remain local exploration artifacts and are intentionally excluded from Git. The approved model establishes the visual direction for the [lower-poly fleet](../fleet-3d/README.md).
